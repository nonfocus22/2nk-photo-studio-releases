# 2NK Photo Studio — installers

This repository holds only the installers (`.msi`) of 2NK Photo Studio, the picture viewer and
editor used at 2NK Group. The program checks the **Releases** here for a newer version
(Help > Check for Updates…) and updates itself.

To install by hand: open **Releases**, download `2nk-photo-studio-<version>-windows-x64.msi`
and double-click it (no administrator rights needed).
